## 1. 概述

本文档描述「模拟考试」从**创建考试 → 获取试题 → 提交答案 → 结算成绩**所需的全部接口。

模拟考试的核心特征：

- 每场考试为**单张试卷**，交卷时一次性提交全部答案；
- 创建考试时必须使用 `type=1`（`2` 为手机考试）；
- 进入考试时 `style=1`；
- 结算调用 `CEndTimeMobil`，**无需加密参数**（实测空值可正常结算）；
- 每场满分 4 分，每日上限 8 分（两场）。

适用范围：服务端对接、自动化客户端、测试工具。本文档不包含手机考试、练习、签到等其他业务流程。

## 2. 环境与公共约定

### 2.1 基础地址

```text
Base URL: http://<platform-host>:<port>
示例:     http://61.150.84.25:100
```

`Base URL` 由部署环境决定，不得硬编码到客户端业务代码中。

### 2.2 请求约定

| 项 | 约定 |
|---|---|
| 协议 | HTTP/1.1（平台为 ASP.NET MVC + nginx）|
| 请求方法 | GET / POST |
| POST 编码 | `application/x-www-form-urlencoded` |
| 会话 | Cookie（首次请求验证码接口后由服务端下发 `ASP.NET_SessionId`）|
| AJAX 标识 | 建议携带 `X-Requested-With: XMLHttpRequest` |
| 字符集 | UTF-8 |

### 2.3 响应类型

| 类型 | 说明 |
|---|---|
| JSON | 形如 `{"success":true,"data":...,"message":""}` |
| 文本 | `|` 分隔字符串（登录/会话/结算结果）|
| HTML | 考试页返回整页 HTML，数据内嵌在 `var vData={...};` |

### 2.4 `Esdt` 参数混淆（平台协议）

部分接口参数（`SetOnlineTestOne`、登录等）必须经过平台自定义的 `Esdt()` 混淆。

算法定义：

1. 对输入字符串逐个 UTF-16 码元取十进制字符串并拼接；
2. 追加 `^`；
3. 追加每个十进制串的长度，用 `,` 连接；
4. 对整个结果执行 ECMAScript 遗留 `escape()`：
   - `A-Z a-z 0-9 @ * _ + - . /` 原样保留；
   - 其余码元 `< 0x100` → `%XX`（大写十六进制）；
   - 其余码元 `>= 0x100` → `%uXXXX`（大写十六进制）。

示例：

```text
输入: 123
十进制串: 495051
长度串:   2,2,2
拼接:    495051^2,2,2
escape:  495051%5E2%2C2%2C2
结果:    495051%5E2%2C2%2C2
```

```text
输入: A1
十进制串: 6549
长度串:   2,2
拼接:    6549^2,2
escape:  6549%5E2%2C2
结果:    6549%5E2%2C2
```

## 3. 前置条件：登录与会话

> 完整登录与会话说明见《登录接口文档》，本节仅保留调用前提。

以下接口仅用于建立会话、获取 `userId` 与当前题库 `examTypeId`，是模拟考试接口的调用前提。

### 3.1 预建会话（获取 Cookie）

```http
GET /Home/GetValidateCode
```

响应为验证码图片（内容可忽略），目的是让服务端下发 `ASP.NET_SessionId`。

### 3.2 登录

```http
POST /PersonWap/GetPersonInfo
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `idcard` | string | 是 | 身份证号，需 `Esdt` 编码 |
| `pwd` | string | 是 | 密码，需 `Esdt` 编码 |
| `yzm` | string | 是 | 固定 `auto` |
| `openid` | string | 是 | 固定空串 |
| `style` | string | 是 | 固定 `0` |
| `auto` | string | 是 | 固定 `true` |

响应（`|` 分隔）：

```text
|<userId>|<userName>|<sessionHash>|<returnCode>
```

- 首段为空表示成功；非空则为服务端错误文案；
- `userId` 即后续接口的 `pid`。

### 3.3 会话快照 / 当前题库

```http
POST /PersonWap/FirstIndexOne
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pid` | string | 是 | 登录返回的 `userId` |

响应（`|` 分隔）：

| 下标 | 含义 |
|---|---|
| 0 | 错误文案，空表示成功 |
| 4 | 当前题库名称 |
| 6 | `examTypeId`（题库 ID）|

## 5. 接口定义

### 5.1 查询可开考试卷

```http
GET /ExamManger/P_Paper/SelectCanRunListOne?rows=20&page=1&pid={pid}&examtypeid={examTypeId}
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `rows` | int | 是 | 每页条数 |
| `page` | int | 是 | 页码，从 `1` 开始 |
| `pid` | string | 是 | 用户 ID |
| `examtypeid` | string | 是 | 题库 ID（来自 3.3）|

响应示例：

```json
{
  "totalCount": 1,
  "success": true,
  "error": "",
  "data": [
    {
      "PaperId": "2069a073-fe4d-4065-9cad-e1f5f951de08",
      "PaperName": "2025陕西煤业矿业公司主要负责人",
      "TotalScore": 100.0,
      "PassingGrade": 80.0
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `data[].PaperId` | 试卷 ID，创建考试使用 |
| `data[].PaperName` | 试卷名称 |
| `data[].TotalScore` | 总分 |
| `data[].PassingGrade` | 及格分 |

---

### 5.2 检查未完成考试（可选）

```http
POST /ExamManger/P_ExamDetail/ExistsNoFinish
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `PaperId` | string | 是 | 试卷 ID |
| `pid` | string | 是 | 用户 ID |
| `type` | int | 是 | 固定 `1` |

响应示例：

```json
{ "success": true, "data": 0 }
```

`data=0` 表示该试卷没有未完成考试；`data>0` 表示存在未完成记录，仍可继续创建新考试（实测允许）。

---

### 5.3 创建临时考试

```http
POST /Home/CreateTempExamOne
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `PaperId` | string | 是 | 试卷 ID |
| `PersonId` | string | 是 | 用户 ID |
| `IDNumber` | string | 是 | 固定空串 |
| `type` | int | 是 | **模拟考试固定 `1`**（手机考试为 `2`）|

响应示例：

```json
{ "success": true, "data": "8c174553-xxxx-xxxx-xxxx-xxxxxxxxxxxx" }
```

`data` 为 `ksmxid`，后续接口必须携带。

> 重要：`type` 必须为 `1`。使用 `2` 会被计为手机考试，模拟考试积分不会增加。

### 5.4 进入考试

```http
POST /P_ExamDetail/SetOnlineTestOne
Content-Type: application/x-www-form-urlencoded
```

参数均需 `Esdt` 编码：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `ksmxid` | string | 是 | 5.3 返回的 `ksmxid`（Esdt）|
| `showBZDA` | string | 是 | 固定 `0` |
| `style` | string | 是 | **模拟考试固定 `1`**（手机考试为 `0`）|
| `vErr` | string | 是 | 固定 `-1` |
| `nc` | string | 是 | 空串 |
| `r` | string | 是 | 空串 |
| `e` | string | 是 | 空串 |
| `b` | string | 是 | 空串 |
| `pid` | string | 是 | 用户 ID（Esdt）|

响应示例：

```json
{ "success": true, "data": null, "message": "操作成功" }
```

`success=true` 即表示考试已进入可作答状态。

### 5.5 获取考试页（试题数据）

```http
GET /P_ExamDetail/OnlineTestOne
```

响应为完整 HTML，试题数据内嵌在：

```js
var vData = { ... };
```

解析方式：截取 `var vData=` 到第一个 `};` 之间的 JSON 对象。

#### vData 关键字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `AllCount` | string | 题目总数（如 `"100"`）|
| `AllQuestionArray` | string | 题目记录，`|` 分隔，每条 22 个字段 |
| `AllQuestionType` | string | 题型分组说明 |
| `Code` | string | 业务返回码（如 `0008`）|
| `ExamTypeId` | string | 题库 ID |
| `ExamTypeName` | string | 题库名称 |
| `Title` | string | 页面标题 |

#### `AllQuestionArray` 单条记录字段（`,` 分隔，共 22 项）

| 下标 | 含义 | 示例 |
|---|---|---|
| 0 | 答题记录 ID | `1^0$1$2` |
| 1 | 题目 GUID | `33b4a29e-...` |
| 2 | 排序 | `1` |
| 3 | 标记 | `0` |
| 4 | **用户答案**（提交前为空）| 空 |
| 5 | 提示 | `0` |
| 6 | 对错标记 | 空 |
| 7 | 卷别 | 空 |
| 8 | 修正 | 空 |
| 9 | 试卷试题 ID | 空 |
| 10 | 分值 | `1` |
| 11 | 顺序号 | `1` |
| 12 | 得分 | `-1` |
| 13 | **正确答案（显示顺序）** | `A` / `ABCD` / `Y` / `N` |
| 14 | 题型 | `1` 单选、`2` 多选、`3` 判断 |
| 15 | 题干（URL 编码）| `4.%e7%9f%bf...` |
| 16 | 选项文本（URL 编码，`#` 分隔）| `A.xxx#    B.xxx` |
| 17 | 保留 | 空 |
| 18 | 服务端答案编码 | `A` |
| 19 | 保留 | 空 |
| 20 | 来源标记 | 空 / `标准` |
| 21 | 来源说明 | `试题编号：...` |

> 交卷使用 **字段 13** 作为用户答案写入字段 4。

---

### 5.6 提交全部答案

```http
POST /Home/DoWriteAnswerAll
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `answer` | string | 是 | 拼接后的答案串 |
| `ksmxid` | string | 是 | 考试会话 ID（明文）|

`answer` 构造规则：

1. 每条题目记录按 `,` 拆分；
2. 取前 15 个字段（下标 0–14）；
3. 字段 4 设置为字段 13 的值；
4. 每条记录用 `,` 连接；
5. 所有记录用 `|` 连接。

响应示例：

```json
{
  "totalCount": 1,
  "success": true,
  "error": "",
  "singleInfo": "",
  "data": [{ "Result": "" }]
}
```

> 该接口只写入答案，不返回分数。

---

### 5.7 结算成绩

```http
POST /Home/CEndTimeMobil
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `ksmxid` | string | 是 | 考试会话 ID（明文）|
| `mxid2` | string | 是 | 固定空串（模拟考试无需加密）|
| `mxid3` | string | 是 | 固定空串 |

响应：

```text
您的分数为：100,合格！|100|合格！
```

| 段 | 含义 |
|---|---|
| 0 | 成绩文案（可直接展示）|
| 1 | 分数（如 `100`）|
| 2 | 是否合格（如 `合格！`）|

失败：

```text
error
```

常见失败原因：

| 现象 | 原因 |
|---|---|
| `error` | `ksmxid` 不存在或已结算 |
| 空响应 | 会话失效或网络错误 |

> 说明：模拟考试也可以使用 `CEndTimeOne`，但该接口要求 AES/RSA 加密参数；使用 `CEndTimeMobil` 并传空值即可完成结算（已实测）。

## 6. 完整调用示例（伪代码）

```text
session = warmUp()                       // GET /Home/GetValidateCode
login = login(idcard, pwd)               // POST /PersonWap/GetPersonInfo
userId = login.parts[1]
info = firstIndexOne(userId)             // POST /PersonWap/FirstIndexOne
examTypeId = info.parts[6]

papers = selectPapers(pid=userId, examtypeid=examTypeId)
paper = papers[0]

exists = existsNoFinish(paper.PaperId, userId)

created = createTempExam(paper.PaperId, userId, type=1)
ksmxid = created.data

setOnlineTestOne(ksmxid, style='1', pid=userId)

html = GET /P_ExamDetail/OnlineTestOne
vData = parseVData(html)
answers = buildAnswers(vData.AllQuestionArray)

doWriteAnswerAll(answer=answers, ksmxid=ksmxid)
result = cEndTimeMobil(ksmxid, mxid2='', mxid3='')
score = result.split('|')[1]
```

## 7. 错误处理与重试建议

| 场景 | 建议 |
|---|---|
| 会话失效 | 重新执行 3.1–3.2 |
| `CreateTempExamOne` 失败 | 检查 `PaperId`、`PersonId`、`type=1` |
| `SetOnlineTestOne.success != true` | 检查 Esdt 编码与 `style=1` |
| `DoWriteAnswerAll.success != true` | 检查 `answer` 拼接格式与 `ksmxid` |
| 结算返回 `error` | 检查 `ksmxid` 是否有效、是否已结算 |
| 网络超时 | 仅对幂等查询重试；创建/提交/结算不要重复调用 |

## 12. 记录标签与查询口径（2026-10-27 实测补充）

`CreateTempExamOne(type=1)` 产生的记录在成绩页/接口中标记为 **「手机模拟」**。

| 创建参数 | 成绩页标签 | 查询过滤 |
|---|---|---|
| `type=1` | 手机模拟 | `GetMyExamListOne?type=3` |
| `type=2` | 手机自测 | `GetMyExamListOne?type=2` |

实测：`GetMyExamListOne?type=3` 返回今天 01:26 的 100 分记录（手机模拟）；`type=0` 只返回理论考试。
恢复/对账必须带正确 `type` 过滤，空列表不等于未提交。
