## 1. 概述

本文档覆盖两类只读数据接口：

- **成绩查询**：我的考试成绩列表、成绩排名；
- **学习统计**：学习时长排名、个人成绩趋势、个人排名分析、单位成绩统计、年龄分布、在线答题统计。

所有接口都需要登录会话，`pid` 为登录返回的 `userId`。

适用范围：服务端对接、自动化客户端、报表页面。本文档不包含考试作答、练习、签到等写操作。

## 2. 公共约定

### 2.1 基础地址与请求

```text
Base URL: http://<platform-host>:<port>
示例:     http://61.150.84.25:100
```

| 项 | 约定 |
|---|---|
| 会话 | Cookie（先登录）|
| 方法 | 以各接口标注为准 |
| POST 编码 | `application/x-www-form-urlencoded` |
| 字符集 | UTF-8 |

### 2.2 `Esdt` 混淆

文档中标注「Esdt」的参数必须经过平台 `Esdt()` 混淆：

1. 逐个 UTF-16 码元取十进制字符串拼接；
2. 追加 `^`；
3. 追加各十进制串长度（`,` 连接）；
4. 执行 ECMAScript `escape()`（`^`→`%5E`、`,`→`%2C`）。

示例：

```text
输入: 123
结果: 495051%5E2%2C2%2C2
```

### 2.3 响应结构

- 列表型：`{ "success": true, "data": [ ... ] }`
- 分页型：`{ "total": 36, "rows": [ ... ] }`
- 排名型：`data` 为数组，`message` 为 `姓名|排名|成绩` 形式的当前用户信息
- 个别接口返回**字符串化 JSON**，需要二次解析（见 5.6、5.7）

## 3. 成绩查询

### 3.1 我的考试成绩列表

```http
GET /ExamManger/P_ExamDetail/GetMyExamListOne?rows=10&page=1&pid={pid}&type=0
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `rows` | int | 是 | 每页条数 |
| `page` | int | 是 | 页码，从 1 开始 |
| `pid` | string | 是 | 用户 ID（明文）|
| `type` | int | 是 | 成绩分类；`0` 默认 |

> 页面实现中：`type` 为 `0/1/4` 时改用 `/ExamManger/P_ExamDetail/GetMyExamList`，其余使用 `GetMyExamListOne`；两者参数与返回结构一致。

响应示例：

```json
{
  "success": true,
  "data": [
    {
      "ExamDetailId": "31bfb3d5-8309-4d67-9723-7a5e1e415710",
      "PersonId": "ec5dab3e-...",
      "State": "已交卷",
      "ShowState": "已交卷",
      "StartTime": "2026-10-08T15:08:09.48",
      "EndTime": "2026-10-08T15:12:21.5",
      "PaperId": "529e111b-...",
      "ExamName": "2025陕西煤业...",
      "ExamType": "手机考试",
      "Mark": 100,
      "WhetherQualified": true
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `ExamDetailId` | string | 考试记录 ID |
| `PersonId` | string | 用户 ID |
| `State` / `ShowState` | string | 状态，如 `已交卷` |
| `StartTime` / `EndTime` | string | 开始/结束时间（ISO 格式）|
| `PaperId` | string | 试卷 ID |
| `ExamName` | string | 考试/试卷名称 |
| `ExamType` | string | 考试类型 |
| `Mark` | number | 得分 |
| `WhetherQualified` | bool | 是否合格 |
| `WhetherExam` | bool | 是否参加考试 |
| `SupplementaryExam*` | - | 补考相关字段（部分为空）|

### 3.2 成绩排名

```http
GET /ExamManger/P_ExamDetail/GetMarkRankingList?rows=10&page=1&begin=2026-10-01&end=2026-10-31&type=1&id=0&pid={pid}
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `rows` | int | 是 | 每页条数 |
| `page` | int | 是 | 页码 |
| `begin` | string | 是 | 开始日期 `yyyy-MM-dd` |
| `end` | string | 是 | 结束日期 `yyyy-MM-dd` |
| `type` | int | 是 | `1` 单位榜，`0` 集团榜 |
| `id` | int | 是 | 榜类别标识，默认 `0` |
| `pid` | string | 是 | 用户 ID |

响应示例：

```json
{
  "success": true,
  "message": "张小赞|12|96.5",
  "data": [
    {
      "Cur": 1,
      "PersonId": "006f7bfd-...",
      "PhotoUrl": "/qyksFiles/person/.../xxx.zp",
      "PersonName": "田小平",
      "DepartmentId": "33cc2ea5-...",
      "DepartmentFullName": "澄合矿业/西卓煤矿/运输区",
      "Mark": 99.5,
      "AllCount": 100,
      "Ranking": 1
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `Cur` | 当前页内序号 |
| `PersonId` | 用户 ID |
| `PhotoUrl` | 头像地址 |
| `PersonName` | 姓名 |
| `DepartmentId` | 单位 ID |
| `DepartmentFullName` | 单位全路径 |
| `Mark` | 得分 |
| `AllCount` | 总题数/总分 |
| `Ranking` | 排名 |
| `message` | `姓名|排名|成绩`，用于顶部“我的排名”展示 |

## 5. 学习统计接口

### 5.1 学习时长排名

```http
POST /ArchiveManger/D_PersonStudyLog/GetStudyTimeRankingListOne
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pid` | string | 是 | 用户 ID（Esdt）|
| `type` | int | 是 | `1` 单位榜，`0` 集团榜 |
| `page` | int | 是 | 页码 |
| `rows` | int | 是 | 每页条数 |
| `begin` | string | 是 | 开始日期 |
| `end` | string | 是 | 结束日期 |

响应字段与 3.2 排名接口一致（`Cur/PersonId/PhotoUrl/PersonName/DepartmentId/DepartmentFullName/Mark/AllCount/Ranking`）。

**实测补充（2026-10-28）**：

- 该接口 `Mark` 为 `null`，学习时长在 `AllCount`；
- 单位是**秒**，证据有两点：
  1. 数值随查询区间累计：单日（2026-10-28）榜首 `5040`（≈84 分钟），10-01~10-28 榜首 `154710`（≈43 小时）；若按分钟，单日 5040 分钟 = 84 小时/天，不可能；
  2. 平台 `Scripts/js/FunctionJS.js` 自带 `FormaterTime(second)`，按 `/3600` 转「时/分/秒」；
- 客户端展示：`AllCount` 秒 → 不足 1 分钟显示秒，不足 1 小时显示分钟，其余显示小时（保留一位）。

## 6. 错误处理

| 场景 | 建议 |
|---|---|
| `success=false` | 展示 `message`，不要无限重试 |
| 返回登录页/首段错误 | 重新登录 |
| `total=0`、`rows=[]` | 正常无数据，不要当失败 |
| 字符串化 JSON 解析失败 | 记录原始响应，检查是否返回了错误页 |
| 日期参数为空 | 部分接口允许空串（5.3），其余按 `yyyy-MM-dd` 传 |

## 9. 考试记录类型与过滤（2026-10-27 实测补充）

`GetMyExamListOne` 的 `type` 与 `ExamType` 标签实测对应关系：

| type | 返回标签 | 说明 |
|---|---|---|
| `0` | 理论考试 | 默认值，**不包含**手机考试记录 |
| `1` | （空）| 当前账号无数据 |
| `2` | 手机自测 | `CreateTempExamOne(type=2)` 的记录 |
| `3` | 手机模拟 | `CreateTempExamOne(type=1)` 的记录 |
| `4` | （空）| 当前账号无数据 |

实测：

```text
GetMyExamListOne type=0 → 36 条，全部为理论考试
GetMyExamListOne type=2 → 20 条，手机自测；第一条 2026-10-27 11:36，100 分
GetMyExamListOne type=3 → 20 条，手机模拟；第一条 2026-10-27 01:26，100 分
```

> 结论：查询成绩/恢复对账必须带正确 `type`；`type=0` 的空结果不能证明手机考试未创建。
