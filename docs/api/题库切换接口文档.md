| 项目 | 内容 |

---

## 1. 概述

本文档描述**切换当前学习题库**所需的接口链路：

```text
单位 → 大类 → 子分类（年份）→ 题库列表 → 保存题库 → 验证
```

关键点：

- 「切换题库」对应平台菜单 **选题库学习**（`/PersonWap/SelectExamType`）；
- 保存的是 `ExamTypeIds`（题库 ID），不是试卷 ID；
- 「选试卷学习」（`SaveExamPaperIdOne`）只改学习试卷，**不改变题库**；
- 切换成功后，通过 `FirstIndexOne` 的题库字段或首页 `M_ExamTypeId` 验证。

适用范围：策略配置、自动化切库、测试工具。本文档不包含考试作答、练习、成绩查询。

## 2. 公共约定

### 2.1 基础地址与请求

```text
Base URL: http://<platform-host>:<port>
示例:     http://61.150.84.25:100
```

| 项 | 约定 |
|---|---|
| 会话 | Cookie（先登录）|
| 方法 | 以各接口标注为准 |
| POST 编码 | `application/x-www-form-urlencoded` |
| 字符集 | UTF-8 |

### 2.2 `Esdt` 混淆

标注「Esdt」的参数必须经过 `Esdt()` 混淆：

1. 逐个 UTF-16 码元取十进制字符串拼接；
2. 追加 `^`；
3. 追加各十进制串长度（`,` 连接）；
4. 执行 ECMAScript `escape()`（`^`→`%5E`、`,`→`%2C`）。

示例：

```text
输入: 123
结果: 495051%5E2%2C2%2C2
```

```text

        │
        ▼
```

## 4. 接口定义

### 4.1 获取单位列表

```http
POST /PersonWap/SelectExamType
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pid` | string | 是 | 用户 ID（明文）|

响应为 HTML 片段，单位信息内嵌在页面中，解析出：

| 字段 | 说明 |
|---|---|
| `DepartmentId` | 单位 ID |
| `Name` | 单位名称 |

实测单位示例：

```text
1                                   股份
2beae4b0-d278-41ed-b9aa-b8e88074b106 澄合矿业
35b56f59-c9eb-4375-bb7e-dee1e4ef38c0 西卓煤矿
```

> 该接口同时是「选题库学习」页面入口，返回的是完整选库页面。

---

### 4.2 获取大类

```http
POST /ExamManger/P_ExamTypeStyle/GetAllTypeEx
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pid` | string | 是 | 用户 ID（Esdt）|
| `unitid` | string | 是 | 单位 ID（Esdt）|

响应示例：

```json
{
  "success": true,
  "data": [
    {
      "Level": 1,
      "DepartmentId": "1",
      "ExamTypeStyleId": 0,
      "StyleName": "安管人员",
      "Code": "0001",
      "Year": ""
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `Level` | 层级：1 大类、2 中间层、3 年份/叶子 |
| `DepartmentId` | 单位 ID |
| `ExamTypeStyleId` | 分类 ID，作为下一层的 `Style` |
| `StyleName` | 分类名称 |
| `Code` | 分类编码，作为下一层的 `Code` |
| `Year` | 年份（部分层级有值）|

实测：单位「股份」返回 4 个大类，例如 `安管人员 / style=0 / code=0001`。

---

### 4.3 获取子分类

```http
POST /ExamManger/P_ExamTypeStyle/GetAllChildTypeEx
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `Style` | string | 是 | 上一层的 `ExamTypeStyleId`（Esdt）|
| `Code` | string | 是 | 上一层的 `Code`（Esdt）|
| `DepartmentId` | string | 是 | 单位 ID（Esdt）|
| `unitids` | string | 是 | 单位 ID 串（Esdt，单个单位时为该 ID）|

响应结构同 4.2（`Level` 递增）。

实测：

```text
父类：安管人员
子类：2026年（Level=3, Year=2026, Style=0, DepartmentId=1）
```

`Level >= 3` 即可拉取题库列表。

---

### 4.4 获取题库列表

```http
GET /ExamManger/P_ExamType/GetExamTypeListExOne?Year=2026&Style=0&DepartmentId={Esdt}&unitids={Esdt}&cname={Esdt}&page=1&rows=50
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `Year` | string | 是 | 年份（来自 4.3）|
| `Style` | string | 是 | 分类 Style |
| `DepartmentId` | string | 是 | 部门 ID（Esdt）|
| `unitids` | string | 是 | 单位 ID 串（Esdt）|
| `cname` | string | 是 | 搜索关键词（空串也必须传，Esdt）|
| `page` | int | 是 | 页码 |
| `rows` | int | 是 | 每页条数 |

响应示例：

```json
{
  "success": true,
  "data": [
    {
      "ExamTypeId": "1496a56d-a1a8-4874-8c71-47256334d10c",
      "ExamTypeName": "2025陕西煤业煤矿防治水细则",
      "DepartmentId": "1",
      "DepartmentName": "股份",
      "QuestionCount": 250,
      "StateName": "正常"
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `ExamTypeId` | 题库 ID（切库时使用）|
| `ExamTypeName` | 题库名称 |
| `DepartmentId` / `DepartmentName` | 所属单位 |
| `QuestionCount` | 题目总数 |
| `StateName` | 状态，如 `正常` |

实测：某子分类返回 38 个题库。

---

### 4.5 切换题库（保存）

```http
POST /ArchiveManger/D_PersonManager/SaveExamTypeIdsOne
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pid` | string | 是 | 用户 ID（Esdt）|
| `ExamTypeIds` | string | 是 | 题库 ID（Esdt）；多题库时用英文逗号连接 |

响应示例：

```json
{
  "success": true,
  "data": "948345e5-eed3-43cd-a5cb-389a038d98e7",
  "message": ""
}
```

`data` 为保存后的当前题库 ID（单题库时）。

> 多题库模式下 `data` 可能是逗号分隔的多个题库 ID。

---

### 4.6 取消题库

```http
POST /ArchiveManger/D_PersonManager/DeleteExamTypeIdsOne
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pid` | string | 是 | 用户 ID（Esdt）|
| `ExamTypeId` | string | 是 | 要移除的题库 ID（Esdt）|

响应示例：

```json
{ "success": true, "data": "剩余题库ID或空串" }
```

取消后若已无题库，首页 `M_ExamTypeId` 为空，考试入口会先进入选题库页。

---

### 4.7 选试卷学习（不是切题库）

```http
POST /ArchiveManger/D_PersonManager/SaveExamPaperIdOne
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pid` | string | 是 | 用户 ID（Esdt）|
| `PaperId` | string | 是 | 试卷 ID（Esdt）|

实测响应（2026-10-30 复核）：

```json
{ "success": true, "data": "948345e5-eed3-43cd-a5cb-389a038d98e7", "message": "" }
```

`data` 返回的是**当前题库 ID**，调用前后 `FirstIndexOne.parts[6]` 不变（实测确认题库未切换）。

**证据级别**：`observed`（2026-10-27 首次实测；2026-10-30 账号持有人授权复核，
`success=true` 且题库 ID 前后一致）。

#### 4.7.1 与考试入口的区别（重要）

实测 `/PersonWap/SelectPaper` 页面（`vData.Title` = 「模拟考试 选择试卷」）时发现：
**该页面并不调用 `SaveExamPaperIdOne`**，它的链路是：

```text
选择试卷（GET /ExamManger/P_Paper/SelectCanRunListOne）
  └─ 点「开始考试」
       ├─ POST /ExamManger/P_ExamDetail/ExistsNoFinish   { PaperId, pid, type: 1 }
       ├─ POST /Home/CreateTempExamOne                    { PaperId, PersonId, IDNumber, type }
       └─ POST /P_ExamDetail/SetOnlineTestOne             { ksmxid(Esdt), style, pid(Esdt), ... }
```

对照表：

| 场景 | 是否调 `SaveExamPaperIdOne` | 说明 |
|---|---|---|
| 考试入口「选择试卷 → 开始考试」 | ❌ 否 | 直接创建临时考试 |
| 「选试卷学习」菜单 | ✅ 是（本文档本节）| 仅设置学习试卷，不建考试 |

> 因此 `SaveExamPaperIdOne` 的**确切菜单位置**目前只有文档记载，尚未在推送页面源码中定位到
> 调用方；若后续需要接入，应先补前端调用点取证。

#### 4.7.2 试卷列表来源

`SaveExamPaperIdOne` 的 `PaperId` 来自可考试卷列表：

```http
GET /ExamManger/P_Paper/SelectCanRunListOne?rows=20&page=1&pid={pid}&examtypeid={examTypeId}
```

`/PersonWap/SelectPaper` 页面实际初始化的分页参数：

```js
pager['rows'] = 20;
pager['page'] = 1;
pager['pid'] = M_PersonId;
pager['examtypeid'] = M_ExamTypeId;   // 按当前题库过滤
```

> **只能选当前题库下的试卷**（`examtypeid` 取自会话中的当前题库）。

#### 4.7.3 试卷题数（列表不返回）

`SelectCanRunListOne` **不返回题数**，只有 `PaperId` / `PaperName` / `TotalScore` / `PassingGrade`。
需要题型与题数时，按 `PaperId` 单独查询（详见《模拟考试接口文档》§5.1.1）：

```http
POST /ExamManger/P_PaperScore/GetChildList
参数: sjid={PaperId}（明文）, findName=''
```

题数 = 所有 `data[].出题数` 之和。实测题数**按试卷人工配置**，与题库大小无关
（详见 `docs/api/samples/paper-score-config/`）。

#### 4.7.4 错误处理

| 场景 | 表现 | 建议 |
|---|---|---|
| `PaperId` 不属于当前题库 | 文档未实测 | 先用 `SelectCanRunListOne` 按 `examtypeid` 过滤，避免跨库传入 |
| `pid` 失效 / 会话过期 | 返回登录页 HTML 或 `success=false` | 按 §8.11 信号表处理，不要重试写操作 |
| `success=false` | 展示 `message` | 不循环重试 |

> 本接口为**写操作**，按主规范 §8.6 不得自动重试。

## 5. 验证切换结果

```http
POST /PersonWap/FirstIndexOne
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pid` | string | 是 | 用户 ID |

响应为 `|` 分隔文本：

| 下标 | 含义 |
|---|---|
| 0 | 空 = 会话有效 |
| 4 | 当前题库名称 |
| 6 | 当前题库 ID（`examTypeId`）|

判定：

```text
parts[6] == 目标 ExamTypeId → 切换成功
```

如果页面上下文可用，也可直接读取前端全局变量 `M_ExamTypeId`。

## 6. 多题库模式

平台支持一个账号保存多个题库（`M_ExamTypeId` 为逗号分隔）：

- `SaveExamTypeIdsOne` 的 `ExamTypeIds` 可传逗号分隔的多个 ID；
- 前端 `M_ExamTypeMSelect == '1'` 时，会展示多题库选择/分类；
- 取消单个题库用 `DeleteExamTypeIdsOne`。

## 8. 错误处理

| 场景 | 建议 |
|---|---|
| `success=false` | 展示 `message`，不要循环重试 |
| 题库列表为空 | 当前分类下无可用题库，换分类或检查单位 |
| 切换后验证不一致 | 重新读取 `FirstIndexOne`，必要时重新登录 |
| 会话失效 | 重新登录后再切库 |
| `Esdt` 编码错误 | 检查 `^`、`,` 是否被正确转义为 `%5E`、`%2C` |
