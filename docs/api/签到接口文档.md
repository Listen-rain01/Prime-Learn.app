## 1. 概述

本文档描述「签到」任务所需的接口。

签到规则（服务端下发）：

```text
每日签到 1 分，连续登录每日多 1 分，每日最多 3 分
```

签到的特征：

- 接口为**幂等写操作**，同一天重复调用不会重复计分；
- 签到成功后，通过每日任务接口确认 `CheckIn` 的 `CurAccumulate`；
- 通过返回的 `message` 区分“首次签到”和“已签到”。

适用范围：服务端对接、自动化客户端、测试工具。本文档不包含考试、练习、阅读等其他任务。

## 2. 环境与公共约定

### 2.1 基础地址

```text
Base URL: http://<platform-host>:<port>
示例:     http://61.150.84.25:100
```

### 2.2 请求约定

| 项 | 约定 |
|---|---|
| 协议 | HTTP/1.1（ASP.NET MVC + nginx）|
| 方法 | `POST`（推荐）|
| 编码 | `application/x-www-form-urlencoded` |
| 会话 | Cookie（先请求验证码接口获取 `ASP.NET_SessionId`）|
| 字符集 | UTF-8 |

### 2.3 `Esdt` 参数混淆

签到接口的 `pid` 必须经过平台 `Esdt()` 混淆：

1. 逐个 UTF-16 码元取十进制字符串并拼接；
2. 追加 `^`；
3. 追加每个十进制串的长度，用 `,` 连接；
4. 对整个结果执行 ECMAScript 遗留 `escape()`：
   - `A-Z a-z 0-9 @ * _ + - . /` 原样保留；
   - 其余 `< 0x100` → `%XX`，`>= 0x100` → `%uXXXX`（大写十六进制）。

示例：

```text
输入: 123
拼接: 495051^2,2,2
结果: 495051%5E2%2C2%2C2
```

## 3. 前置条件：登录与会话

> 完整登录与会话说明见《登录接口文档》，本节仅保留调用前提。

### 3.1 预建会话

```http
GET /Home/GetValidateCode
```

用于获取 `ASP.NET_SessionId`。

### 3.2 登录

```http
POST /PersonWap/GetPersonInfo
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `idcard` | string | 是 | 身份证号（Esdt）|
| `pwd` | string | 是 | 密码（Esdt）|
| `yzm` | string | 是 | 固定 `auto` |
| `openid` | string | 是 | 空串 |
| `style` | string | 是 | 固定 `0` |
| `auto` | string | 是 | 固定 `true` |

响应（`|` 分隔）：

```text
|<userId>|<userName>|<sessionHash>|<returnCode>
```

首段为空表示成功，`userId` 为后续接口的 `pid`。

## 4. 接口定义

### 4.1 执行签到

```http
POST /ArchiveManger/D_PersonAccumulate/CheckInOne
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pid` | string | 是 | 用户 ID，需 `Esdt` 编码 |

请求示例（表单）：

```text
pid=1234%5E4
```

响应示例（首次签到）：

```json
{
  "success": true,
  "data": "1239|3",
  "message": "操作成功"
}
```

响应示例（今日已签到）：

```json
{
  "success": true,
  "data": "1239|3",
  "message": "已签到"
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| `success` | bool | 是否成功 |
| `data` | string | 服务端签到标识（`|` 分隔，原样保存，不解析）|
| `message` | string | `操作成功` = 本次签到成功；`已签到` = 今日已签到 |

> `data` 的具体含义由服务端定义，客户端只需保证 `success=true`，并用任务接口确认积分。

---

### 4.2 查询签到结果（每日任务）

```http
GET /AccumulateManger/S_Accumulate/GetPersonTodayAccumulateOne?pid={Esdt(userId)}
```

从 `data` 数组中找到 `Criterion = "CheckIn"` 的条目：

```json
{
  "AccumulateName": "签到",
  "AccumulateRule": "每日签到1分，连续登录每日多1分，每日最多3分",
  "Accumulate": 1,
  "MaxAccumulate": 3,
  "CurAccumulate": 2,
  "CurAccumulateState": "",
  "Criterion": "CheckIn"
}
```

判定：

```text
签到完成度 = CurAccumulate / MaxAccumulate
CurAccumulate > 0 即表示今日已签到
```

## 5. 幂等与重试

| 场景 | 行为 |
|---|---|
| 同一天重复调用 `CheckInOne` | 返回 `success=true`、`message=已签到`，不重复计分 |
| 网络超时 | 可重试（幂等）|
| 会话失效 | 返回登录页/错误文案，需重新登录 |
| `success=false` | 读取 `message`，不要重试到成功为止 |

## 6. 完整调用示例（伪代码）

```text
warmUp()                                  // GET /Home/GetValidateCode
login = login(idcard, pwd)                // POST /PersonWap/GetPersonInfo
userId = login.parts[1]

result = post('/ArchiveManger/D_PersonAccumulate/CheckInOne', {
    pid: esdt(userId)
})

if (result.success) {
    tasks = getTodayAccumulate(esdt(userId))
    checkIn = tasks.first(t => t.Criterion == 'CheckIn')
    score = checkIn.CurAccumulate
}
```
