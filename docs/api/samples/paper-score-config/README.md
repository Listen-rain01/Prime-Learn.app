# 试卷出题数配置 接口样本

| 项 | 值 |
|---|---|
| 接口 | `POST /ExamManger/P_PaperScore/GetChildList` |
| 采集时间 | 2026-10-30 |
| 采集人 | 账号持有人授权 + 实现者实测 |
| 平台版本 | 陕西煤业-素质兴安-全员考试（`61.150.84.25:100`）|
| 采集方式 | 登录后按 `sjid` 逐份试卷查询（`tool/score_sample_probe.dart`）|

## 请求参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `sjid` | string | 是 | 试卷 ID（即 `SelectCanRunListOne` 返回的 `PaperId`），**明文** |
| `findName` | string | 否 | 搜索关键词；实测传空串或不传均可 |

> 参数名是 `sjid`，不是 `PaperId`。用 `PaperId` 会返回 `success:true` 但 `data:[{}]`（空对象），
> 属于容易踩的坑。来源：`/Scripts/Bus/ExamManger/js/PaperChildList.js`
> （`Ext.apply(thiz.baseParams, { findName: findName, sjid: r.data.PaperId })`）。

## 响应结构

平台返回的是**非标准 JSON**（键未加引号），形如：

```text
{totalCount:3,success:true,error:"",singleInfo:"",data:[{"题型":"单项选择题",...}]}
```

因此不能直接用严格 JSON 解析器；客户端需按宽松解析或先补引号。

| 字段 | 说明 |
|---|---|
| `totalCount` | 配置条目数（不是题数）|
| `data[].题型` | `单项选择题` / `多项选择题` / `判断题` |
| `data[].出题数` | **该题型+考查分类下抽多少题**（字符串数字）|
| `data[].题库总量` | 该分类下可选题目池大小 |
| `data[].分值` | 每题分值（如 `"1.00"`）|
| `data[].试题分类` | 题库名称 |
| `data[].考查分类` | 考查分类；为空串表示不区分分类 |
| `data[].P题型ID` | `1` 单选、`2` 多选、`3` 判断 |
| `data[].P考试类型ID` | 即题库 ID（`ExamTypeId`）|

## 实测数据（4 份试卷）

| 题库（题量）| 试卷 | 配置 | 合计题数 |
|---|---|---|---|
| 2020学法规（5881）| 2020五职矿长考试 | 18 条，按 6 个考查分类拆分 | **100** |
| 2025安全规程（3985）| 2025陕西煤业煤矿安全规程 | 单选 50 + 多选 10 + 判断 40 | **100** |
| 2025安全规程（3985）| 学法规、提素质专项考试 | 单选 40 + 多选 10 + 判断 50 | **100** |
| 2025注安法规（2672）| 2025陕西煤业注安法规 | 单选 50 + 多选 10 + 判断 40 | **100** |

**关键结论**：

1. 题库大小（5881 / 3985 / 2672）**不影响**考试题数，只决定「可选池子」大小；
2. 同一题库的两份试卷（第 2、3 行）题型分配不同（50/10/40 vs 40/10/50），
   证明题数是**人工按试卷配置**的，不是按题库大小自动算的；
3. 题数 = 所有 `data[].出题数` 之和。

## 与 `SelectCanRunListOne` 的关系

`SelectCanRunListOne`（选试卷列表）**不返回题数**，只有 `PaperId` / `PaperName` /
`TotalScore` / `PassingGrade`。要显示题数，必须对每份试卷额外调用本接口。

## 脱敏说明

样本中仅保留题型配置与题量，不含用户身份信息；题库 ID、试卷 ID 为平台业务标识，
非凭据，原样保留以便复现。
