## 1. 概述

本文档描述「阅读学习」从**分类 → 文章 → 详情 → 完成阅读**所需的全部接口。

阅读学习对应的积分任务为 `Criterion = "StudyKnowledge"`（知识学习）：

```text
每日学习 1 个知识点积 1 分，最多 1 分
```

特征：

- 完成阅读调用一次写接口即可计分，按日封顶；
- 页面上的“已阅读 0 秒/获得 1 分”中，阅读时长不影响计分；
- 文章分页由子分类驱动，`typeid` 使用子分类 ID。

适用范围：服务端对接、自动化客户端、测试工具。本文档不包含考试、练习、签到等其他任务。

## 2. 环境与公共约定

### 2.1 基础地址

```text
Base URL: http://<platform-host>:<port>
示例:     http://61.150.84.25:100
```

### 2.2 请求约定

| 项 | 约定 |
|---|---|
| 协议 | HTTP/1.1（ASP.NET MVC + nginx）|
| 方法 | `GET` |
| 会话 | Cookie（先请求验证码接口获取 `ASP.NET_SessionId`）|
| 字符集 | UTF-8 |

### 2.3 `Esdt` 参数混淆

部分参数（`pid`、`zsid`、`did`）必须经过 `Esdt()` 混淆：

1. 逐个 UTF-16 码元取十进制字符串并拼接；
2. 追加 `^`；
3. 追加每个十进制串的长度，用 `,` 连接；
4. 对整个结果执行 ECMAScript 遗留 `escape()`：
   - `A-Z a-z 0-9 @ * _ + - . /` 原样保留；
   - 其余 `< 0x100` → `%XX`，`>= 0x100` → `%uXXXX`（大写十六进制）。

示例：

```text
输入: 123
拼接: 495051^2,2,2
结果: 495051%5E2%2C2%2C2
```

## 3. 前置条件：登录与会话

> 完整登录与会话说明见《登录接口文档》，本节仅保留调用前提。

### 3.1 预建会话

```http
GET /Home/GetValidateCode
```

### 3.2 登录

```http
POST /PersonWap/GetPersonInfo
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `idcard` | string | 是 | 身份证号（Esdt）|
| `pwd` | string | 是 | 密码（Esdt）|
| `yzm` | string | 是 | 固定 `auto` |
| `openid` | string | 是 | 空串 |
| `style` | string | 是 | 固定 `0` |
| `auto` | string | 是 | 固定 `true` |

响应（`|` 分隔）：

```text
|<userId>|<userName>|<sessionHash>|<returnCode>
```

首段为空表示成功，`userId` 为后续接口的 `pid`。

## 5. 接口定义

### 5.1 查询一级分类

```http
GET /LearnManger/L_KnowledgeType/GetAllTypeOne
```

响应示例：

```json
{
  "success": true,
  "data": [
    {
      "KnowledgeTypeId": "a4d24110-778c-4631-bf85-59a46781d1fc",
      "TypeName": "股份事故案例",
      "DepartmentId": "1"
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `KnowledgeTypeId` | 分类 ID，用于 5.2 |
| `TypeName` | 分类名称 |
| `DepartmentId` | 单位 ID，用于 5.2 的 `did` |

---

### 5.2 查询子分类

```http
GET /LearnManger/L_KnowledgeType/GetAllChildTypeOne?pid={Esdt(父分类ID)}&did={Esdt(DepartmentId)}
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pid` | string | 是 | 父分类 ID（Esdt）|
| `did` | string | 是 | 父分类的 `DepartmentId`（Esdt）|

响应示例：

```json
{
  "success": true,
  "data": [
    {
      "KnowledgeTypeId": "cb754fb8-72b7-49db-863c-f6964536cfc3",
      "TypeName": "巷道掘进"
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `KnowledgeTypeId` | 子分类 ID，作为 5.3 的 `typeid` |
| `TypeName` | 子分类名称 |

> 一级分类下没有子分类时，可直接用一级分类 ID 作为 `typeid`。

---

### 5.3 查询文章列表

```http
GET /LearnManger/L_KnowledgeSubject/GetStudyOne?typeid={子分类ID}&pid={userId}&page=1&rows=20
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `typeid` | string | 是 | 子分类 ID（明文，不 Esdt）|
| `pid` | string | 是 | 用户 ID（明文）|
| `page` | int | 是 | 页码，从 1 开始 |
| `rows` | int | 是 | 每页条数 |

响应示例：

```json
{
  "success": true,
  "data": [
    {
      "KnowledgeSubjectId": "d04d3209-f721-43e0-8c6f-c750278a6508",
      "Title": "寸草塔二矿31204回风绕道顶板伤人事故",
      "Style": 0,
      "CreateTime": "2026-10-20T10:00:00",
      "WeekRead": ""
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `KnowledgeSubjectId` | 文章 ID（完成阅读的 `zsid`）|
| `Title` | 文章标题 |
| `Style` | `0` 普通文章，非 0 为 PDF |
| `CreateTime` | 创建时间 |
| `WeekRead` | 本周阅读标记，可能为空 |

---

### 5.4 打开文章详情（可选）

```http
GET /PersonWap/StudyDetail?pid={userId}&id={文章ID}&typeid={子分类ID}&s=0&pdf={Style}&Title={标题}&ct={创建时间}
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pid` | string | 是 | 用户 ID（明文）|
| `id` | string | 是 | 文章 ID |
| `typeid` | string | 是 | 子分类 ID |
| `s` | int | 是 | 固定 `0` |
| `pdf` | int | 是 | 文章 `Style` |
| `Title` | string | 是 | 文章标题（URL 编码）|
| `ct` | string | 是 | 创建时间（空格分隔，无毫秒）|

响应为 HTML 片段；仅用于展示，**计分不依赖此接口**。

---

### 5.5 完成阅读（计分）

```http
GET /ArchiveManger/D_PersonAccumulate/StudyKnowledgeOne?pid={Esdt(userId)}&zsid={Esdt(文章ID)}
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `pid` | string | 是 | 用户 ID（Esdt）|
| `zsid` | string | 是 | 文章 ID（Esdt）|

响应示例：

```json
{ "success": true, "data": null, "message": "" }
```

| 字段 | 说明 |
|---|---|
| `success` | 是否成功；`true` 即完成阅读并计分 |
| `message` | 失败时的错误文案 |

> 该接口按日封顶 1 分；重复调用不会重复计分。

## 6. 查询知识学习任务

```http
GET /AccumulateManger/S_Accumulate/GetPersonTodayAccumulateOne?pid={Esdt(userId)}
```

从 `data` 中找到 `Criterion = "StudyKnowledge"` 的条目：

```json
{
  "AccumulateName": "知识学习",
  "AccumulateRule": "每日学习1个知识点积1分，最多1分",
  "Accumulate": 1,
  "MaxAccumulate": 1,
  "CurAccumulate": 1,
  "CurAccumulateState": "已阅读0秒/获得1分",
  "Criterion": "StudyKnowledge"
}
```

判定：

```text
CurAccumulate >= 1 即表示今日知识学习已完成
```

> `CurAccumulateState` 中的“已阅读0秒”不影响计分。

## 7. 幂等与重试

| 场景 | 行为 |
|---|---|
| 同一文章重复调用 `StudyKnowledgeOne` | 返回 `success=true`，不重复计分 |
| 换另一篇文章再调用 | 当日已达上限时不再加分 |
| 网络超时 | 可重试（幂等）|
| 会话失效 | 需重新登录 |
| `success=false` | 读取 `message`，不要循环重试 |

## 8. 完整调用示例（伪代码）

```text
warmUp()                                   // GET /Home/GetValidateCode
login = login(idcard, pwd)                 // POST /PersonWap/GetPersonInfo
userId = login.parts[1]

types = get('/LearnManger/L_KnowledgeType/GetAllTypeOne').data
parent = types[0]

children = get('/LearnManger/L_KnowledgeType/GetAllChildTypeOne', {
    pid: esdt(parent.KnowledgeTypeId),
    did: esdt(parent.DepartmentId)
}).data

articles = get('/LearnManger/L_KnowledgeSubject/GetStudyOne', {
    typeid: children[0].KnowledgeTypeId,
    pid: userId,
    page: 1,
    rows: 20
}).data

article = articles[0]
result = get('/ArchiveManger/D_PersonAccumulate/StudyKnowledgeOne', {
    pid: esdt(userId),
    zsid: esdt(article.KnowledgeSubjectId)
})

tasks = getTodayAccumulate(esdt(userId))
knowledge = tasks.first(t => t.Criterion == 'StudyKnowledge')
```

| 2026-10-27 | 分类 → 子分类 → 文章 | 子分类“巷道掘进”返回 11 篇文章 |
