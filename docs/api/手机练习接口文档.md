## 1. 概述

本文档覆盖**手机练习**（今日任务 `Criterion=MobileExercises`，"每日每练习50题加1分，最多6分"）
的完整链路：入口、进入练习、练习页数据结构、单题提交、退出同步。

> **范围声明**：`AGENTS.md` v1 明确「不做手机练习」（平台侧计数延迟/不稳定）。
> 本文档为**协议取证**，供对账、排查与后续扩展使用，v1 客户端不接入。
> 练习时长任务（`Criterion=StudyTime`）与手机练习共用同一条链路，服务端按
> `StudyTimeAccumulateId` / `MobileExercisesAccumulateId` 分别累计。

---

## 2. 公共约定

与《成绩查询与学习统计接口文档》一致：

- 会话 Cookie（先登录）；`pid` 为登录返回的用户 ID；
- 标注「Esdt」的参数须经平台 `Esdt()` 混淆；
- 本链路请求/响应中**除 Esdt 参数外均为明文 GUID**。

---

## 3. 链路总览

```text
每日积分页（/PersonWap/AccumulateFinish）
  └─ XXExam("MobileExercises")
       ├─ M_ExamTypeId 为空 → POST /PersonWap/SelectExamType → SaveExamTypeIdsOne（见《题库切换接口文档》）
       └─ 已有题库 → POST /P_ExamDetail/SetOnlineStuday
                         │
                         ▼
            GET /P_ExamDetail/OnlineStuday（整卷题库内联页面）
                         │  每答一题
                         ▼
            POST /ArchiveManger/D_PersonStuday/SetQuestionOne
                         │  退出练习 CloseStuday()
                         ▼
            POST /PersonWap/SyncPersonStat → 回首页
```

## 4. 接口详情

### 4.1 今日任务查询（只读）

```http
GET /AccumulateManger/S_Accumulate/GetPersonTodayAccumulateOne?pid={Esdt(pid)}
```

样本见 `docs/api/samples/today-accumulate/`。手机练习条目关键字段：

| 字段 | 说明 |
|---|---|
| `AccumulateName` | `手机练习` |
| `AccumulateRule` | 每日每练习50题加1分，最多6分 |
| `CurAccumulate` | 今日已得分 |
| `CurAccumulateState` | `已答145题/获得2分`（今日已答题数）|
| `Criterion` | `MobileExercises` |
| `AccumulateId` | 即练习页的 `MobileExercisesAccumulateId` |

### 4.2 进入练习（写）

```http
POST /P_ExamDetail/SetOnlineStuday
Content-Type: application/x-www-form-urlencoded

Id={Esdt(examTypeId)}&Id2={Esdt('')}&style={Esdt('0')}&style2={Esdt('')}
&txid={Esdt('')}&pid={Esdt(pid)}&wx={Esdt(wx)}
```

| 参数 | 说明 |
|---|---|
| `Id` | 题库 ID（Esdt）|
| `style` | 固定 `'0'`（练习）|
| `pid` | 用户 ID（Esdt）|

响应为 JSON `{success}`；成功后前端跳转 `/P_ExamDetail/OnlineStuday`。

### 4.3 练习页（只读，数据全内联）

`GET /P_ExamDetail/OnlineStuday` 返回 HTML，页面内联脚本定义：

- `allShiTi`：**整卷题目数组**（实测 3985 题全部预载，翻题不发请求）；
- `onlineAllCount`（总题数）、`onlineCur`（当前题号，从 1 起）；
- `M_Code` / `M_ExamTypeId` / `M_Style` / `M_PersonId`；
- `M_StudyTimeAccumulateId` / `M_MobileExercisesAccumulateId`（两个任务 ID，随每题提交）。

页面脚本：`/Scripts/Bus/ExamManger/OnlineStuday/main.js`（选项 `onclick=SD(...)`）。

#### 单条题目记录（`,` 分隔，共 22 项，与考试 `AllQuestionArray` 同构）

| 下标 | 含义 | 实测样例 |
|---|---|---|
| 0 | 答题记录 ID（进度）| `2^3$2$0$1` |
| 1 | 题目 GUID | `338fc337-5129-4481-8a43-a91d4cfe1a25` |
| 2 | 排序 | `2` |
| 3 | 标记 | `0` |
| 4 | 用户答案（提交前为空）| 空 |
| 5 | 提示 | `0` |
| 6 | 对错标记 | 空 |
| 7 | 卷别 | 空 |
| 8 | 修正 | 空 |
| 9 | 试卷试题 ID | 空 |
| 10 | 分值 | `1` |
| 11 | 顺序号 | `2` |
| 12 | 得分 | `-1` |
| 13 | **正确答案（显示顺序）** | `D` / `ABCD` / `Y` / `N` |
| 14 | 题型 | `1` 单选、`2` 多选、`3` 判断 |
| 15 | 题干（URL 编码）| `%e4%be%9d%e6%8d%ae...` |
| 16 | 选项文本（URL 编码，`#` 分隔）| `A.xxx#B.xxx#...` |

### 4.4 单题提交（写）

```http
POST /ArchiveManger/D_PersonStuday/SetQuestionOne
Content-Type: application/x-www-form-urlencoded
```

| 参数 | 类型 | 说明 |
|---|---|---|
| `questionid` | string | 题目 GUID（**明文**）|
| `pid` | string | 用户 ID（**明文**）|
| `examtypeid` | string | 题库 ID（**明文**）|
| `answer` | string | 单选 `A-D`；判断 `Y/N`；多选多字母拼接 |
| `code` | string | 站点编码（如 `0008`）|
| `pparms` | string | `练习时长分|练习时长单次秒|练习时长封顶|手机练习分|每题数|手机练习封顶|当前题号`（`|` 分隔）|
| `mystyle` | string | `0` |
| `StudyTimeAccumulateId` | string | 练习时长任务 GUID（**明文**）|
| `MobileExercisesAccumulateId` | string | 手机练习任务 GUID（**明文**）|

实测样例（`pparms=10|7200|10|1|50|6|1`）。

响应：

```json
{ "success": true, "data": "1", "message": "" }
```

- `data == "0"` → **答错**；`data == "1"` → **答对**。

#### 提交语义（前端 SubmitSelect，实测双向验证）

- 用户答案 ≠ `f[13]`（答错）→ 直接提交显示字母；
- 用户答案 == `f[13]`（答对）→ **提交 `f[18]`（服务端答案编码）**。

> `f[13]` 是打乱显示顺序后的正确答案，`f[18]` 是其在服务端原始顺序中的编码；
> 答对时页面自动换算。服务端只比对提交值，不校验知识。

### 4.5 退出练习（写）

前端 `CloseStuday()` → 先同步统计再回首页：

```http
POST /PersonWap/SyncPersonStat
Content-Type: application/x-www-form-urlencoded
pid={Esdt(pid)}
```

响应 `{ "success": true, "data": "", "message": "" }`。

## 5. 行为约束（页面 JS 层）

| 约束 | 规则 |
|---|---|
| 答题间隔 | 强制 ≥1 秒，快速连答弹「答题时间间隔1秒，请勿快速连续答题！」|
| 同题点击 | 超过 8 次踢回首页（`style=2` 时超过 20 次）|
| 自动跳题 | 单选/判断答对后自动 `ToNext` |

---

## 6. 错误处理

| 场景 | 建议 |
|---|---|
| `success=false` | 展示 `message`，不无限重试 |
| 返回登录页 | 重新登录 |
| 计数不更新 | 平台侧延迟（练习题数/时长计数有跳变，见实测记录），以复查值为准 |
